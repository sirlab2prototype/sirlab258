# Capstone

Clean reimplementation of the Indy7 capstone system.

## Verified baseline

Verified on real Indy7:

- Ubuntu 24.04
- ROS 2 Jazzy
- Neuromeka `indy-ros2` (`jazzy-indyDCP3`)
- Indy controller: ROS 2 driver connection
- `/joint_states` feedback
- MoveIt planning
- Real robot trajectory execution from RViz

Python environment:
- Python 3.12
- `neuromeka==3.4.2.2`
- `empy==3.3.4`
